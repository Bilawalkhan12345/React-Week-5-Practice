===== Installation and configuration of Tailwind css in react project ====
1. Write this command in VS Code terminal "npm install tailwindcss @tailwindcss/vite"
2. Now configurationin the project go to file "vite.config.js" and add

import react from '@vitejs/plugin-react'
import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite' === ADD THIS === 

// https://vite.dev/config/
export default defineConfig({
  plugins: [react(), tailwindcss()],  === ADD ", tailwindcss()"  HERE === 
});


3. Now import tailwindcss in the file you want  "@import "tailwindcss";"


======  JSX Rules  ======

WRONG 
return(
    <h1> Hello </h1>
    <p> Welcome </p>
)

Correct 
return(
  <div>  
    <h1> Hello </h1>
    <p> Welcome </p>
  </div>
)

Better way Instead of div react provides Fragment

Correct 
return(
  <>  
    <h1> Hello </h1>
    <p> Welcome </p>
  </>
)


======  JSX Rules 2 ======
Close Every Tag
<img /> , <br /> , <imput /> , <hr />



======  JSX Rules 3 ======

In Html = onclick, tabindex, readonly
JSX : onClick , tabIndex, readOnly
